# Build4Fun
A repository for introductionary apprentices. Instead of configuring and creating docker compose files, to spin up docker services, it bases itself on the scratch approach. Block coding.

## Navigation guide
The Build4Fun repository is section in three parts: docs, housing the documentation of this repository. src, housing the code of the web application. build, housing the necessary scripts and docker compose files for this application.
