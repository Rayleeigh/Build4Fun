# Crack4Fun challenge catalog

Each program's `program.json` defines its public instructions and progressive
hints. Filesystem has four flags, Forensics six, Network Analysis three, and
Web/API four. Identifiers such as `fo-02` map to brace-only flags generated for
the current session; never add actual flag values or verifier secrets here.

Evidence is generated by `apps/crack4fun/sandbox/artifacts.py`; the prepared web
scenario lives in `apps/crack4fun/portal/server.py`. Changing identifiers or flag
counts requires updating those generators and the integration solve paths.
These catalogs are independent of Build4Fun and Code4Fun lessons.

See the [course plan](../../docs/crack4fun/files-plan.md) and
[implementation guide](../../docs/crack4fun/implementation.md).
