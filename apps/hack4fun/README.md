# Crack4Fun

Planned beginner capture-the-flag addon. Apprentices explore a prepared website,
inspect HTML, CSS, and JavaScript, and use curl to understand API requests and
retrieve flags. Exercises can include basic filesystem navigation.

Implementation belongs here; lessons belong in `challenges/hack/` and sandbox
image locations will be decided during implementation. No runnable Crack4Fun application exists yet.

See [repository architecture](../../docs/monorepo.md).

The application was previously named Hack4Fun. This placeholder retains its
legacy directory name. See the [naming and colour convention](../../docs/naming-and-colours.md).
